Задеплоить index.html на GitHub Pages
Создать репозиторий, загрузить файл, включить Pages
git30 мин

Самая важная первая победа — увидеть свой сайт в интернете по реальному URL. Всё остальное строится на этом фундаменте.

  • Создать аккаунт на GitHub (если нет) и новый публичный репозиторий
  • Загрузить скачанный index.html через веб-интерфейс (Add file → Upload)
  • Зайти в Settings → Pages, выбрать branch: main, папку: /(root), нажать Save
  • Через 2 минуты открыть https://username.github.io/repo-name/
Результат задания
Сайт открывается, видна форма входа

js20 мин

Научиться редактировать код и сразу видеть результат. Понять как работает localStorage — где хранятся данные.

  • Открыть index.html в редакторе (VS Code или даже Notepad++)
  • Найти строку const MASTER_PASS = 'tutor123' и заменить пароль
  • Загрузить обновлённый файл на GitHub (там же Add file → Upload, заменить)
  • Войти на сайт с новым паролем, создать тестового ученика, добавить 3–4 блока

Изменить цвета и шрифт под свой стиль
Поработать с CSS-переменными в :root
css1–2 ч

Перестать использовать чужой дизайн и сделать платформу «своей». CSS-переменные — главный инструмент для этого.

  • Найти блок :root { --bg: ...; --accent: ... } в начале <style>
  • Поменять --accent (основной цвет кнопок) и --bg (фон) на свои цвета
  • Добавить кастомный Google Font: вставить <link> в <head> и применить в body

Настроить GitHub Sync и проверить запись данных
Personal Access Token, GitHub API, fetch()
api45 мин

Данные в localStorage не переносятся между браузерами. GitHub Sync решает это — и заодно учит работать с REST API через fetch().

  • Создать Personal Access Token на github.com/settings/tokens с правом repo
  • Войти на сайт как репетитор, нажать ⚙ GitHub, ввести данные
  • Сохранить страницу ученика, зайти в репозиторий — проверить появился ли файл data/students.json
  • Открыть DevTools → Network, нажать «Сохранить» и посмотреть на запрос PUT к api.github.com
Результат задания
Файл data/students.json появился в репозитории

Репетитор должен знать как ученик справляется с тестами. Добавим сохранение результатов и простую аналитику.

Создать таблицы students, blocks; подключить JS SDK
sqlrest apiдень

GitHub как хранилище данных — хак. Supabase — настоящая PostgreSQL база данных с бесплатным планом. Это следующая ступень.

  • Подключить @supabase/supabase-js через CDN (unpkg)
  • Заменить функции getData() / setData() на вызовы Supabase

Настоящая авторизация через Supabase Auth
Email/пароль вместо самописной проверки строки
authsecurityдень

Хранить пароли в открытом тексте — уязвимость. Supabase Auth делает хеширование и сессии за вас.

  • Включить Email провайдер в Supabase → Authentication → Providers
  • Заменить loginTutor() на supabase.auth.signInWithPassword()
  • Для учеников — создавать Supabase-пользователей программно через Admin API или хранить их credentials в отдельной таблице с хешем bcrypt
  • Настроить Row Level Security (RLS) — ученик видит только свои строки
Результат задания
Пароли хешированы, ученик не может достать чужие данные

Кнопки ↑↓ работают, но drag-and-drop — это UX уровня Notion. Изучить один из главных паттернов интерфейсов.

Real-time: ученик видит изменения без перезагрузки
Supabase Realtime subscriptions
websocketrealtime3 дня

Репетитор редактирует страницу — ученик видит изменения мгновенно. Это WebSocket под капотом Supabase.

  • Включить Replication для таблицы pages в Supabase
  • В кабинете ученика подписаться: supabase.channel('page').on('postgres_changes', ...)
  • При получении изменений — перерендерить блоки без перезагрузки страницы
  • Добавить индикатор «онлайн» — мигающую точку когда подключение активно
Результат задания

Мобильное приложение через PWA
manifest.json + service worker = установка на телефон
pwaoffline2–3 дня

Без App Store, без Kotlin — превратить сайт в приложение, которое устанавливается на телефон и работает офлайн.

  • Создать manifest.json с иконками, названием, display: standalone
  • Написать service-worker.js: кешировать HTML, CSS, KaTeX при первом запуске
  • Зарегистрировать SW в index.html: navigator.serviceWorker.register()
  • Проверить в Chrome DevTools → Application → Manifest и → Service Workers
  • Открыть на Android → «Добавить на главный экран»
Результат задания
Иконка на телефоне, страницы грузятся офлайн

Монетизация: подключить платёжную систему
Stripe или CloudPayments, тарифы Free / Pro
paymentsбизнеснеделя

Финальный шаг — из учебного проекта в реальный бизнес. Billing — самая сложная часть любого SaaS.

  • Создать Stripe аккаунт (или CloudPayments для СНГ), настроить продукты и цены
  • Ограничить Free план: не больше 3 учеников
  • Добавить Supabase Edge Function для создания Stripe Checkout Session (бэкенд нельзя делать на фронте)
  • Вебхук от Stripe → обновлять поле plan у репетитора в БД
  • Показывать баннер «Обновите план» при превышении лимита
Результат задания
